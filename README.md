# SailHighSea TorrentSearch

A small, portable torrent search tool for Windows, macOS and Linux, written in C11 with raylib. It searches public torrent indexes, merges the answers by info-hash and hands the magnet link to your own torrent app. It never downloads or shares files itself.

> Only download material you have the right to. Search results come from third-party sites.

It has the same look as SailHighSea SimpleSync: custom title bar, icon rail, nine themes (System, Light, Dark, Flat 98, Win98, Mac System 7, Mac Platinum, Linux CDE, Linux GNOME 2).

## Features

- **31 sources** switched on or off in Settings. The Pirate Bay, YTS, Nyaa (and Sukebei, off by default), Torrents.csv, BitSearch and Knaben use JSON/RSS APIs with their own parsers with seeders, size and age; the older sites are scraped for magnet and hash links. Many of the older sites are dead or blocked in some countries; they show as offline and are skipped.
- **Search suggestions** as you type: your recent searches first, then online suggestions. Up/Down to pick, Space takes a suggestion into the box so you can keep typing, Enter searches. The box has a normal cursor (Left, Right, Home, End, Delete, paste).
- **Result cards** with seeders, leechers, size, age and category. Click a card for the info hash, upload date, file count and a **file tree** with sizes.
- **Buttons per result:** open the magnet link, copy it, star it into Favorites, or save the `.torrent` file to your Downloads folder (when a public .torrent cache has it).
- Sort by seeders, size, newest or name. Search history. Optional update check against GitHub releases.

Run `SailHighSea-TorrentSearch.exe [words to search for]` to start with a search.

## Where things are kept

Settings, favorites and history are plain text files next to the program (`torrentsearch-settings.txt`, `torrentsearch-favorites.tsv`, `torrentsearch-history.txt`). Delete them to reset.

## Build

Windows (MSYS2 UCRT64 gcc, cmake, ninja):

```powershell
.\scripts\build.ps1 -Test
```

Each build is copied to `test\SailHighSea-TorrentSearch-v0.0.1-dev-N.exe` (the newest three are kept). `-Console` makes a Debug build with raylib's log window, `-Run` starts the app afterwards.

Linux and macOS:

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build
ctest --test-dir build
```

Linux needs the usual raylib development packages (X11, OpenGL) and `curl` at run time; macOS needs `curl` too (it ships with both).

## Releases

`.github/workflows/build-release.yml` builds Windows x64 and ARM64, Linux x64 and macOS arm64, runs the tests and publishes a GitHub release:

- push to `main`: stable release (v0.0.1, v0.0.2, ...)
- push to `dev`: pre-release (v0.0.1-dev-1, ...)
- pull request or manual run: build and tests only

## Project layout

- `src/main.c` - window, title bar, icon rail, pages, result cards, search box
- `src/ui/` - theme and icons (shared with SimpleSync); `icon_data.h` is generated by `scripts/make-icons.ps1`
- `src/engine/` - `search_engine` (source table, parsers, worker threads, magnet builder, file lists, suggestions), `json_lite`, `result_store` (favorites and history). No raylib in here, so the tests run headless
- `src/platform/` - HTTP (WinHTTP, or curl elsewhere), tray, updater and OS helpers
- `tests/engine_test.c` - parser and store tests that need no network
- `external/raylib` - raylib 5.5 with the same local patches as SimpleSync

## Development notes

- Do not include `windows.h` in a file that includes `raylib.h` (name clashes). Keep engine code free of raylib.
- To add a site, add a row to the `SOURCES` table in `src/engine/search_engine.c` and raise `SHS_SRC_COUNT` in `search_engine.h` (at most 32, because sources are a bit mask).
- URLs reach curl on Linux and macOS, so build them with `ShsUrlEncode`; `ShsHttpGet` rejects unusual characters.
- Dev flags: `--type=text` fills the search box without searching, `--expand` opens the first result after a search.
